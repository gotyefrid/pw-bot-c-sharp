# BotCH

> [!CAUTION]
> ## Использование на свой страх и риск!

Бот для Perfect World: фармит мобов и собирает ресурсы. Читает память клиента и вызывает функции самой игры — без
нажатий клавиш и кликов мышью, поэтому окно игры может быть в фоне, а за соседним клиентом можно играть.

![Windows](https://img.shields.io/badge/Windows-x86-0078D6) ![.NET Framework](https://img.shields.io/badge/.NET_Framework-4.8-512BD4) ![WPF](https://img.shields.io/badge/UI-WPF-68217A)

> 💬 **Вопросы по боту — в Telegram-чате: https://t.me/botch_pw**

## Что умеет

- **Бить мобов** — в радиусе от центра, всех подряд или только из списка; сначала тех, кто бьёт персонажа или пета;
  атака скиллом или макросом персонажа, возврат в центр, сбор лута (монеты, предметы, по списку — названия или группы:
  оружие, броня, украшения, банки, снаряды, предметы ДК, корм пета).
- **Собирать ресурсы** — обходит маршрут из точек и копает выбранное. Ресурс рядом с опасным мобом пропускает, напали —
  улетает вверх, а не улететь — уходит к следующей точке; с опасными не дерётся никогда. Запоминает, где и когда ресурсы появляются (общий блокнот для всех копий бота).
- **Пет** — свой для земли, воды и воздуха: призвать, воскресить, вылечить, покормить выбранным кормом (или не кормить).
- **Банки** HP и MP.
- **Ремонт** — износилось надетое: долетает до выбранного NPC, чинит всё и возвращается на фарм; на Comeback можно
  чинить из сумки, никуда не летая.
- **Статистика** персонажа на вкладке «Бот»: за сессию, день, неделю, месяц — сколько работал, убито мобов (своих и пета),
  смерти на фарме, опыт и уровни, подобранные деньги, ремонты, сливы опыта (когда начинались и сколько шли), подобранное и
  выкопанное по названиям. Хранится в `stats\<сервер>\<ник>` рядом с exe, по файлу на месяц.
- **Несколько клиентов** — в одном окне вкладка на персонажа, как в браузере: у каждой своё подключение и свой бот.
  Открытые вкладки запоминаются и при запуске подключаются к своим клиентам. Окна игры подписываются «Ник PID».
- **Персонажи** — список ваших персонажей (сервер, ник, класс, уровень, комментарий): «Открыть» запускает клиент, входит
  персонажем и подключает бота. Пароль хранится зашифрованным средствами Windows. На всех трёх серверах бот входит
  сам: принимает соглашение, вписывает логин и пароль, выбирает ник — кнопками окон через функции игры, без клавиш; рядом видно, на каком он этапе. Нет связи с сервером — пробует ещё раз через
  1, 3, 5 минут, клиент завис — перезапускает его, неверный пароль — сразу говорит. «Отмена» останавливает вход.
- **Переподключение** — связь с сервером пропала или клиент закрылся, пока бот работал (после «Старта»):
  бот закрывает клиент, входит заново персонажем из «Персонажей» и продолжает тот же режим. После «Стопа» не переподключается.
- **Уведомления в Telegram** — пока бот работает, пишет вам о новых сообщениях в чате: кто написал и что. Можно выбрать
  личные, группу, общий чат (вкладка «Чат»). Ники в уведомлении копируются нажатием. Ответьте на уведомление — ваш
  персонаж шепнёт ответ тому, кто написал; `/w Персонаж Ник текст` — шепнуть самому, `/list` — кто подключён. Команды
  бот принимает только из вашего chat_id, шептать можно и при остановленном боте.
- **Кликер** — свой сценарий из шагов по кругу: у шага действие (например, нажать клавишу или поднять предмет) и условия
  (например, «цели нет» или «HP меньше 50 %»), их можно объединять через «И», «ИЛИ», «НЕ». Нажатие уходит в окно своего
  клиента, а не в активное, и срабатывает, даже когда окно игры в фоне.

Все настройки в окне бота подписаны: наведите мышь на поле — появится подсказка.

## Серверы

| Профиль          | Сервер                                          |
|------------------|-------------------------------------------------|
| `pwclassic136`   | PW Classic 1.3.6 (`client.exe`)                 |
| `comeback136`    | Comeback 1.3.6 (`ElementClient.exe`, `ElementClient_test.exe`) |
| `comeback146`    | Comeback 1.4.6                                  |

Сервер для бота — это файл профиля `.jsonc`: адреса, смещения и функции игры с сигнатурами. Новый сервер — новый профиль,
код менять не нужно. Профили вшиты в exe; свой профиль можно положить в папку `profiles` рядом с exe.

## Запуск

1. Запустите клиент игры и войдите персонажем — или потом откройте его кнопкой **Персонажи…** в боте.
2. Запустите `Notes.exe` — это один файл, ставить ничего не нужно.
3. Выберите сервер, клиент и режим, настройте под персонажа и нажмите **Старт**.

Для второго клиента запустите `Notes.exe` ещё раз из той же папки и выберите в новом окне другой клиент. Копий — сколько
угодно: настройки берутся по серверу и нику персонажа.

| Где                               | Что                                                                       |
|-----------------------------------|---------------------------------------------------------------------------|
| `settings.json`                   | подключение и шаблон настроек для новых персонажей — общие для всех окон |
| `characters\<сервер>\<ник>.json`  | настройки персонажа                                                       |
| `characters\accounts.json`        | «Персонажи»: логины, пароли (зашифрованы), клиент и комментарий           |
| `logs\<сервер>\<дата> <ник>.log`  | лог персонажа, файл на каждый день                                        |
| `logs\notes-<дата>.log`           | лог, пока персонаж не подключён                                           |
| `%AppData%\Notes\`                | блокнот ресурсов и журнал их появления — общие для всех копий бота       |

## Сборка

Нужны Visual Studio 2022 или Build Tools с .NET Framework 4.8.

```
msbuild PwBot.sln -restore -p:Configuration=Release
```

Бот — `src/Notes.App/bin/Release/net48/Notes.exe`, тесты — `tests/Notes.Tests/bin/Release/net48/Notes.Tests.exe`.

```
src/Notes.Core      логика: память, профили серверов, снимок мира, вызовы игры, мозг, настройки
src/Notes.App       окно (WPF)
tools/Notes.Probe   консоль для проверок на живом клиенте: снимок мира, сигнатуры, поиск полей
tools/Notes.Patcher отдельный патчер client.exe (окно WPF): быстрый полёт (кладётся рядом с игрой, делает бэкап .orig)
tests/Notes.Tests   тесты без игры: подделки мира и снимок памяти живого клиента
```

## Безопасность

Бот не меняет код игры. Перед каждым вызовом функции игры сверяется её сигнатура: функция не на месте — вызова нет.
Отдельный `Notes.Patcher` по желанию правит `client.exe` на диске (с бэкапом `.orig`) — это не обязательно для бота.

Боты запрещены правилами большинства серверов — пользуйтесь на свой риск.

## Виртуалка

Сервер может отказать с «Запрещено запускать игру через виртуальные машины» — он узнаёт VM по модели и
серийнику диска. Это лечится настройкой самой виртуалки, без правки клиента: [docs/vmware.md](docs/vmware.md).
