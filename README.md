# BotCH

Бот для Perfect World: фармит мобов и собирает ресурсы. Читает память клиента и вызывает функции самой игры — без
нажатий клавиш и кликов мышью, поэтому окно игры может быть в фоне, а за соседним клиентом можно играть.

> 💬 **Вопросы по боту — в Telegram-чате: https://t.me/botch_pw**

## Что умеет

- **Бить мобов** — в радиусе от центра, всех подряд или только из списка; сначала тех, кто бьёт персонажа или пета;
  атака скиллом, возврат в центр, сбор лута (монеты, предметы, по списку).
- **Собирать ресурсы** — обходит маршрут из точек и копает выбранное. Ресурс рядом с опасным мобом пропускает, напали —
  улетает вверх. Запоминает, где и когда ресурсы появляются (общий блокнот для всех копий бота).
- **Пет** — свой для земли, воды и воздуха: призвать, воскресить, вылечить, покормить.
- **Банки** HP и MP.
- **Несколько клиентов** — по боту на клиент, окна игры подписываются «Ник PID».
- **Кликер** — в работе.

Все настройки в окне бота подписаны: наведите мышь на поле — появится подсказка.

## Серверы

| Профиль          | Сервер                                          |
|------------------|-------------------------------------------------|
| `pwclassic136`   | PW Classic 1.3.6                                |
| `comeback136`    | Comeback 1.3.6 (`ElementClient.exe`)            |
| `comeback136test`| Comeback 1.3.6 (`ElementClient_test.exe`)       |
| `comeback146`    | Comeback 1.4.6                                  |

Сервер для бота — это файл профиля `.jsonc`: адреса, смещения и функции игры с сигнатурами. Новый сервер — новый профиль,
код менять не нужно. Профили вшиты в exe; свой профиль можно положить в папку `profiles` рядом с exe.

## Запуск

1. Запустите клиент игры и войдите персонажем.
2. Запустите `BotCH.exe` — это один файл, ставить ничего не нужно.
3. Выберите сервер, клиент и режим, настройте под персонажа и нажмите **Старт**.

Одна папка — один бот. Для второго клиента скопируйте папку с ботом.

| Где                     | Что                                                                      |
|-------------------------|--------------------------------------------------------------------------|
| `settings.json`         | подключение и шаблон настроек для новых персонажей                      |
| `characters\<ник>.json` | настройки персонажа                                                      |
| `logs\`                 | лог, файл на каждый день                                                 |
| `%AppData%\BotCH\`      | блокнот ресурсов и журнал их появления — общие для всех копий бота      |

## Сборка

Нужны Visual Studio 2022 или Build Tools с .NET Framework 4.8.

```
msbuild PwBot.sln -restore -p:Configuration=Release
```

Бот — `src/BotCH.App/bin/Release/net48/BotCH.exe`, тесты — `tests/BotCH.Tests/bin/Release/net48/BotCH.Tests.exe`.

```
src/BotCH.Core      логика: память, профили серверов, снимок мира, вызовы игры, мозг, настройки
src/BotCH.App       окно (WPF)
tools/BotCH.Probe   консоль для проверок на живом клиенте: снимок мира, сигнатуры, поиск полей
tests/BotCH.Tests   тесты без игры: подделки мира и снимок памяти живого клиента
```

## Безопасность

Бот не меняет код игры. Перед каждым вызовом функции игры сверяется её сигнатура: функция не на месте — вызова нет.
Опасные функции (выход из игры, отпустить пета) запрещены в профиле и не вызываются никогда.

Боты запрещены правилами большинства серверов — пользуйтесь на свой риск.
